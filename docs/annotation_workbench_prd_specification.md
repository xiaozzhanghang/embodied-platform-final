# 具身智能平台 - 动作范围标注工作台（PRD 功能需求规格说明书）

> **文档用途**：供前端、后端及算法研发团队进行功能开发、接口联调与验收测试。  
> **核心场景**：具身智能（Embodied AI）机器人多视角数据采集、SOP 动作步骤时序范围切分标注、质检审核与数据交付。

---

## 一、 整体设计与页面架构

### 1.1 页面交互形态
- **沉浸式全屏布局**：页面采用 `100vh` 纯净全屏布局，隐藏左侧全局菜单侧边栏，为多视角视频与时序轴提供最大化可视面积。
- **自适应栅格**：
  - **左侧（占比 60%）**：四相机多视角视频矩阵同步播放区。
  - **右侧（占比 40%）**：动作步骤管理、操作手柄录制、多选批量操作区。
  - **底部（固定高度）**：动态录制 HUD 横幅 + 播放进度条 + 多彩动作时序轴 + 播放控制器。

---

## 二、 模块一：顶部全局导航与任务元信息栏 (Top Header)

### 2.1 UI 布局与字段
1. **任务标题**：展示当前任务类型（如 `test_job_范围标注 (具身智能标注工作台)`）。
2. **数据元信息 Tag 组**：
   - `任务ID`：Task ID（如 `8751`）
   - `实例ID`：Instance ID（如 `19884`）
   - `数据序号 (Episode ID)`：当前多视角视频序列唯一标识（如 `744108`）
3. **右上角全局操作区**：
   - `[保存标注]` 按钮（Primary Button，支持 `Ctrl+S / Cmd+S` 快捷保存）。
   - `[返回任务列表]` 按钮。

### 2.2 交互与业务规则
- 点击 `保存标注`：向后端持久化当前各步骤的 `startFrame`、`endFrame` 及标注元数据，并弹出轻提示 `保存成功`。

---

## 三、 模块二：左侧多相机 4 视角视频矩阵区 (Left Multi-Camera Viewports)

### 3.1 UI 布局与视口划分
采用 `2 × 2` 栅格矩阵，严格同步渲染 4 路具身智能传感器数据流：
1. **CAM 01 (左上)**：`camera_head_left_color`（头部主视角 RGB - Top Head）
2. **CAM 02 (右上)**：`camera_head_right_color`（头部右侧辅助视 - Head Right）
3. **CAM 03 (左下)**：`camera_hand_left_color`（左机械臂腕部特写 - Wrist L）
4. **CAM 04 (右下)**：`camera_hand_right_color`（右机械臂腕部特写 - Wrist R）

### 3.2 交互与动态渲染逻辑
- **多视角严格帧级同步**：4 个视频视口的当前渲染帧必须与全局 `currentFrame` 严格 1:1 锁步对齐（支持单帧前进/后退、精准定位）。
- **实时录制/播放状态标识**：
  - **播放中**：视口左上角展示红底白色呼吸角标 `● REC LIVE 30FPS`，中间展示实时动态扫描网格。
  - **动作跟踪框 (AI Bounding Box)**：播放时视口内展示 `🎯 机械爪跟踪` 动态引导线框。
  - **暂停态**：左上角角标变为灰色 `已暂停`，中心展示半透明播放指示器。

## 四、 模块三：右侧动作步骤管理与录制区 (Right Action Steps Studio)

### 4.1 顶部「操作手柄录制」控制栏 (Toolbar)
1. **选中状态展示**：右上角展示当前选中的步骤标签（如 `已选步骤 #03`）。
2. **开始录制按钮 `[开始 [Q]]`**：
   - **交互动作**：
     1. 将当前选中的步骤 `startFrame` 设为 `currentFrame`；
     2. 自动开启视频 30FPS 顺畅向前播放 (`isPlaying = true`)；
     3. 开启实时录制模式 (`isRecordingStepId = selectedId`)；
     4. 底部时间轴色块伴随播放向右动态延展拉伸；
     5. 触发全局轻提示：`🔵 步骤 #X 已在 [N 帧] 开始实时录制！`
3. **标记结束按钮 `[标记 [R]]`**：
   - **交互动作**：
     1. 校验 `currentFrame > startFrame`（若小于等于起始帧，拦截并报错 `结束帧必须大于起始帧`）；
     2. 将当前步骤的 `endFrame` 锁定为 `currentFrame`；
     3. 自动暂停视频播放 (`isPlaying = false`)；
     4. 结束实时录制模式 (`isRecordingStepId = null`)；
     5. 触发全局轻提示：`✅ 步骤 #X 录制完成！区间已锁定为 [X - Y 帧]`。

### 4.2 步骤列表工具条 (Header Bar)
- **步骤总数计数**：展示 `步骤列表 (N)`。
- **一键全选 / 取消全选按钮**：快速切换多选批量操作状态。
- **`[增加步骤]` 按钮**：
  - 检查视频总时长上限（900 帧）：若所有步骤帧数已占满 900 帧，提示 `帧数不足无法新增`；
  - 否则在末尾追加默认时长 100 帧的新步骤，并自动将焦点选定到新步骤。

### 4.3 批量操作浮动栏 (Batch Actions Sticky Bar)
- **触发条件**：当勾选任意 1 个或多个步骤的 Checkbox 时在列表顶部浮现。
- **操作项**：
  1. `📋 批量复制所选 (M) 步`：
     - 计算批量步骤总时长 `totalBatchDur`；
     - 校验当前总占用 + `totalBatchDur` 是否超过总上限 900 帧；
     - 若通过，自动在末尾克隆对应步骤，并按顺序顺延对齐帧数。
  2. `🗑️ 批量删除`：一键移除已选中的步骤，并对剩余步骤重新计算编号与顺延时间轴。
  3. `取消`：清空勾选项。

### 4.4 步骤卡片详细交互 (Step Card Spec)
每张步骤卡片包含以下元素：
1. **左侧专属颜色垂直标识线（5px 宽）**：
   - 与下方时间轴上该步骤的色块颜色 **1:1 严格一致**（青色、紫色、蓝色、绿色等）。
2. **多选 Checkbox**：点击切换批量操作勾选态（事件隔离，不触发卡片选中）。
3. **拖拽调换手柄 `⠿`**：
   - 鼠标按住手柄可在列表中**上下拖拽调换步骤先后顺序**；
   - 调换完成后，系统**自动重新计算步骤的时间轴顺序（每步开始帧 = 上一步结束帧 + 1，保持各步骤独立帧长不变）**。
4. **步骤序号 Badge**：如 `01`、`02`、`03`。
5. **步骤名称编辑框 (`Input`)**：
   - 点击文本框自由编辑修改 SOP 动作描述（添加 `draggable={false}` 与 `stopPropagation`，避免误触拖拽）。
6. **`[复制单步]` 按钮**：
   - 校验剩余可用帧数是否足够复制该单步时长；
   - 在当前步骤下方立即克隆一个相同动作，开始帧自动设为 `上一步结束帧 + 1`，时长与被复制步骤完全一致；
   - 界面自动平滑滚动 (`scrollIntoView`) 至新卡片。
7. **`[删除步骤]` 图标按钮**：点击删除，并重新对齐后续步骤时序。
8. **帧数控制组（3 栏栅格）**：
   - `起始帧 (InputNumber)`：修改时实时更新，限制 `>= 0` 且 `< 结束帧`。
   - `结束帧 (InputNumber)`：修改时实时更新，限制 `> 起始帧` 且 `<= 900`。
   - `帧总数 (Input 禁用态)`：自动实时计算公式：`endFrame - startFrame`（只读，灰色背景）。

## 五、 模块四：底部实时录制动态 HUD 横幅 (Live Recording HUD Alert)

- **显示条件**：当点击 `[开始 [Q]]` 或按 `Q` 键进入录制模式时动态浮现；点击 `[标记 [R]]` 或完成录制时自动淡出收起。
- **UI 风格与视觉反馈**：
  - 科技蓝渐变背景与微发光蓝边框：`background: linear-gradient(90deg, #eff6ff 0%, #dbeafe 50%, #eff6ff 100%)`。
  - 左侧呼吸闪烁科技蓝圆点：`box-shadow: 0 0 10px #2563eb`。
  - 实时动态文本：
    > `🔵 步骤 #X「动作名称」正在实时录制` | Tag: `起始: 120f ➔ 实时: 285f (+165 帧)` | `播放随帧实时延展中`
  - 右侧提供快捷操作按钮：`[按 [R] 结束标记]`。

## 六、 模块五：底部多彩时序轴与高亮激光游标 (Timeline & Playhead)

### 6.1 播放滑块轴 (Playback Slider)
- 顶部展示极细精准进度条，支持全范围快速拖动定位，右侧展示当前帧与总帧数（如 `316 / 900 帧`）。

### 6.2 多步骤时序色块轨道 (Multi-Color Temporal Track)
1. **色块渲染算法**：
   - `left: (step.startFrame / totalFrames) * 100%`
   - `width: ((step.endFrame - step.startFrame) / totalFrames) * 100%`
2. **实时录制动态延展反馈**：
   - 当正在录制某步骤时，该步骤色块实时呈现 **蓝白动态交替发光斜纹 (Barber-pole Stripes)** 与高亮外发光；
   - 伴随视频播放，该色块的**右侧边缘紧随红色游标向右逐帧向右实时拉伸**！
3. **点击与选中联动**：
   - 点击时序轴上的任意步骤色块，立即选中该步骤，并将红色游标定位至点击处的帧；
   - 选中的色块呈现 `scaleY(1.1)` 放大高亮与深色聚焦边框。

### 6.3 3px 鲜艳高亮激光红游标 (Red Laser Playhead)
1. **视觉规范**：
   - 顶部帧数悬浮角标：纯红背景 `#ff1e1e`，加粗白色文字 `{currentFrame}f`。
   - 下方倒三角指针：纯红 `#ff1e1e`，向下精准指向时间轴。
   - 垂直激光线：**3px 实心鲜红激光条**，带全屏发光投影 `box-shadow: 0 0 10px 1.5px rgba(255, 30, 30, 0.95)`。
2. **交互行为**：
   - **鼠标拖拽自由寻帧**：支持在时间轴任意位置按住鼠标左键（或触摸屏）左右平滑拖动，实时精准逐帧 Scrubbing；
   - **游标穿透自动选步**：拖拽游标滑过步骤区间时，右侧卡片列表自动高亮对应的动作步骤。

## 七、 模块六：底部视频播放控制器与全局提交区 (Player & Actions Bar)

### 7.1 播放控制组
- **首帧 / 尾帧按钮**：`[|<]` 跳至 0 帧，`[>|]` 跳至 900 帧。
- **高精度时间码**：展示毫秒级当前时间 `⏱️ 00:00:10.533 / 00:00:30.000`。
- **快退 10 帧 / 快进 10 帧**：微调当前帧。
- **核心播放/暂停按钮 `▶️ / ⏸️`**：
  - 32px 蓝色圆形按钮，点击播放/暂停；
  - 若已到末尾，点击自动重置回 0 帧并重新播放。
- **倍速切换器**：支持 `1.0x`、`1.5x`、`2.0x` 平滑变速播放。

### 7.2 质检审核与完成标注提交区
- **`[生成标注模版]`**：提取当前已切分好的动作步骤，保存为可复用的 SOP 模版。
- **`[完成标注 (T)]`**：主操作提交按钮，点击完成该 Episode 的切图标注并提交下一条。
- **`[质检不合格]` / `[抽检驳回]`**：供 QA 审核员进行错误标记与工单退回。

## 八、 全局键盘快捷键矩阵 (Keyboard Hotkeys)

| 快捷键 | 功能名称 | 触发动作与交互逻辑 |
| :--- | :--- | :--- |
| **`Q` / `q`** | **开始录制** | 将当前步骤起始帧设为当前游标帧，自动启动视频 30FPS 流畅播放与时序轴实时动态延展 |
| **`R` / `r`** | **标记结束** | 将当前步骤结束帧设为当前游标帧，自动暂停视频播放，锁定时间轴并退出录制态 |
| **`Space` (空格)** | **播放 / 暂停** | 全局快速在播放与暂停状态之间无缝切换 |
| **`T` / `t`** | **完成标注提交** | 校验所有步骤完整性并一键保存提交当前标注数据 |
| **`←` / `→` (左右方向键)** | **逐帧微调** | 每次按键向前/向后微调 1 帧 |
| **`Shift + ← / →`** | **快退 / 快进** | 每次按键快退 / 快进 10 帧 |
