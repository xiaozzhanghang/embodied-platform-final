# 具身智能交互式 3D 场景展示系统 (Embodied 3D Viewer)

> 参考基准：[BiGym 2.0 (Imperial College London / SWIRL Lab)](https://bigym2.github.io/)  
> 核心特性：基于 WebGL 真正的实时 3D 空间渲染、支持骨骼动画与 23-DOF 机器人关节运动学驱动、多室内任务场景、完整相机交互与遥测属性面板。

---

## 一、系统架构与技术栈

- **框架基座**：React 18 + TypeScript + Vite 5
- **3D 渲染引擎**：Three.js + React Three Fiber (`@react-three/fiber`)
- **3D 辅助与控制**：Drei (`@react-three/drei`)
- **模型格式**：标准 GLB / glTF 2.0 PBR 材质与层级关节树
- **图标与交互**：Lucide React + 原生 CSS / CSS Modules (科技感 HUD、暗黑主题、毛玻璃拟态)
- **运行模式**：首版纯前端离线运行，已预留机器人状态 API 与 WebSocket 实时通讯接口。

---

## 二、功能特性说明

### 1. 真实 3D 空间结构与环境渲染
- **空间结构**：室内地面与墙壁、防眩光操作台 / 厨房台面、橱柜与洗碗机机体。
- **环境光照**：ACESFilmic 色调映射、定向主光 (PCF 柔和阴影)、青色轮廓光、自发光 HUD 导引线。
- **地面网格**：带有空间刻度的具身智能坐标网格（动态淡出），完美呼应 BiGym 2.0 空间标定环境。

### 2. 人形机器人模型与驱动源切换
提供四种无缝切换的驱动模式：
1. **✨ Spline 超写实高精人形机器人 (默认推荐)**：
   - 官方地址：`https://prod.spline.design/qBnmld15EAMuLsZo/scene.splinecode`
   - 采用高端工业科技感 PBR 材质（黑曜石高光面罩、矩阵 LED 眼、碳化纤维编织胸甲、哑光银金属双臂）。
   - 支持流畅的视线鼠标物理追踪交互、多级关节点击对象识别与遥测数据联动。
2. **Unitree G1 23-DOF 仿生双臂人形机器人**：
   - 依据 Unitree G1 真实尺寸（1.32m / 35kg）构建的完整关节层级树（胸腔、头部广角传感器、双肩、双肘、手腕与并联灵巧手爪）。
   - 支持逐帧运动学控制与闭环抓放协同。
3. **RobotExpressive (GLB 真实骨骼动画模型)**：
   - 加载真实骨骼绑定的 GLB 模型文件，挂载 `useAnimations` 动画混合器。
4. **基础几何体占位模型 (Fallback Placeholder)**：
   - 当外部资源缺失时自动触发降级机制，带有明确的 `⚠️ [基础几何体占位模型]` 浮层标识，保证系统 100% 可用。

### 3. 四大预制动作演示 (Motion Demonstration)
- **待机待命 (Idle)**：机器人自然呼吸起伏、双臂微屈待命、头部微幅环境扫描。
- **关节抬手 (Raise Arm)**：右肩关节前屈抬起 75°，手腕调平，手爪微张进入就绪位姿。
- **抓取纸箱 (Pick Object)**：多阶段连贯抓取——俯身前伸接近桌面目标纸箱、手爪精准合拢夹持、平稳垂直抬升抱持。
- **放置托盘 (Place Object)**：向右旋转回转臂体、精准对齐目标托盘、平稳缓降释爪放置。
- 支持时间轴滑块拖拽 (0% - 100% 任意跳帧)、播放/暂停、倍速切换 (0.5x, 1.0x, 2.0x)、单次/循环切换。

### 4. 完整的相机交互与保护机制
- **鼠标左键**：平滑旋转视角。
- **鼠标滚轮**：平滑无级放大与缩小。
- **鼠标右键**：平移视角与场景观察点。
- **平滑惯性**：启用 OrbitControls 阻尼因子 (`dampingFactor: 0.06`)。
- **穿模保护**：限制极角 `maxPolarAngle = 87°`（严格防止穿入地面），设置最小距离 `0.8m` 限制穿入模型内部。
- **多视角预设**：一键切换「场景全景」、「机器人特写」、「操作台俯角」、「头部视点 (Head Cam)」、「手腕抓取视点 (Wrist Cam)」，自带平滑补间动画。

### 5. 对象拾取高亮与具身遥测属性面板
- **光标悬浮识别**：指针变手型并弹出目标识别 HUD 浮标。
- **点击选中高亮**：底座全息光环脉冲，外围高对比度标记。
- **属性面板**：实时展示空间坐标 (X, Y, Z)、三维物理尺寸、材料与质量、伺服状态、机体温度、动力电池、位姿置信度。
- **空白处取消选中**：点击任意非对象区域即刻退出选中状态。

### 6. 多场景切换
- **🍳 厨房家庭操纵 (BiGym 2.0 经典场景)**
- **🏭 工业装配操作台**
- **📐 标准几何标定场**

## 四、本地运行指南

### 1. 独立运行 3D 展示系统

```bash
cd embodied-3d-viewer
npm install
npm run dev
```

启动后在浏览器打开：`http://localhost:3001/`

### 2. 生产构建验证

```bash
npm run build
npm run preview
```

### 3. 主原型大屏集成
主项目 `http://localhost:3000/screen` 已集成此 3D 页面，作为中心主视觉看板的默认实时 3D 孪生主图展示。
